🔫 12게이지 산탄총 & 탄환 규칙

• 매 장전마다 CRT 모니터에 실탄(LIVE)과 공포탄(BLANK) 개수가 표시된 뒤 무작위 순서로 장전됩니다.
• 상대에게 발사: 실탄이면 상대 체력 -1(쇠톱 시 -2), 공포탄이면 피해 없음. 발사 후 상대에게 턴이 넘어갑니다.
• 자신에게 발사: 실탄이면 본인 체력 감소 후 턴 종료. 공포탄이면 피해 없이 보너스 턴을 얻어 한 번 더 행동합니다!

⚡ 체력(전하) 및 서든데스

• 체력이 0이 되면 해당 라운드/매치에서 패배합니다.
• 1인용 3라운드에서는 체력이 2칸 이하로 떨어지면 제세동기 전선이 절단되어 이후 담배나 약으로 회복할 수 없습니다.

🖱️ 화면 조작 및 행동 순서

  • 자동 아이템 보급: 라운드/장전 시작 시 보급 상자가 자동으로 열리며 랜덤 아이템이 각 플레이어 칸에 순차 배치됩니다.
  • 아이템 사용: 하단 슬롯의 아이템을 클릭하면 작은 팝업이 뜨며, [ 선택 ]을 누르면 즉시 사용되고 [ 취소 ]를 누르면 닫힙니다.
  • 샷건 발사: 테이블 중앙의 3D 산탄총을 직접 클릭하거나 하단 [ 🔫 샷건 들기 ] 버튼을 누른 뒤 대상을 선택해 발사합니다.
  • 3D 시점 회전: 마우스를 움직이면 1인칭 시선이 테이블 주위로 자연스럽게 움직입니다.

🤖 1인용 모드 (vs AI 딜러)

• 1라운드(체력 2, 아이템 없음) → 2라운드(체력 4, 상자 아이템 2개) → 3라운드 서든데스(체력 5, 상자 아이템 4개) 순으로 진행됩니다.
• 딜러는 남은 탄환 확률과 돋보기·대포폰 정보를 계산하여 아이템과 사격 대상을 결정합니다.

🌐 실시간 온라인 비밀번호 방 & 관전

• 방장이 방 제목과 비밀번호를 설정해 방을 만들면 HTML을 공유받은 다른 기기/네트워크 친구 화면에도 실시간으로 방이 표시됩니다.
• 2명 이상 모이면 방장이 게임을 시작할 수 있으며, 진행 중인 방에 비밀번호를 치고 들어가면 관전 모드로 실시간 관전합니다.
